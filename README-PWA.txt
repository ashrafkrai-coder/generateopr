PENJANA OPR SEKOLAH — PAKEJ PWA

Kandungan
- index.html: aplikasi penjana OPR A4
- manifest.json: maklumat pemasangan aplikasi
- sw.js: cache app-shell supaya aplikasi boleh dibuka semula tanpa internet selepas muat pertama
- icons/: ikon aplikasi

Cara guna
1. Terbitkan semua fail dan folder ini di root laman web menggunakan hosting HTTPS.
2. Buka URL laman pada telefon.
3. Android/Chrome: tekan “Pasang App” atau pilih “Install app” pada menu pelayar.
4. iPhone/iPad: buka dalam Safari, tekan Share/Kongsi, kemudian “Add to Home Screen/Tambah ke Skrin Utama”.

Paparan OPR dicetak pada saiz A4 potret. Fail logo dan gambar yang dipilih diproses setempat dalam pelayar. Untuk fungsi luar talian, buka aplikasi sekali semasa internet tersedia.
